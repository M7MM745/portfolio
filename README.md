# 📁 موقعي الشخصي — نسخة عصرية (Portfolio v4)

🔗 **الموقع على Cloudflare:** https://m7mm745-portfolio.mhamd77deep.workers.dev/
🔗 **نسخة GitHub Pages:** https://m7mm745.github.io/portfolio/
📦 **المستودع:** https://github.com/M7MM745/portfolio

> للنشر على Cloudflare لاحقًا: نفّذ `npx wrangler deploy` من داخل هذا المجلد بعد تسجيل الدخول بـ `npx wrangler login`.

موقع شخصي متجاوب بالكامل، ثنائي اللغة (عربي RTL / إنجليزي LTR)، bootstrap-free يعمل مباشرة بفتح ملف `index.html` — لا يحتاج أي خطوة بناء (No Build Step).

## 🚀 التشغيل

الطريقة الأسهل: افتح `index.html` مباشرة في المتصفح.

أو لتشغيل خادم محلي (مفضل لاختبار الروابط والـ SEO):

```powershell
python -m http.server 8899
# ثم افتح: http://127.0.0.1:8899/4-modern-portfolio/
```

## 📂 الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الهيكل، بيانات SEO، مكتبة الأيقونات SVG، الروابط الثابتة |
| `styles.css` | التصميم كاملًا (متغيرات الألوان، الوضعان، التجاوب، الحركات) |
| `app.js` | كل النصوص والمحتوى القابل للتعديل + التفاعلات |
| `assets/` | صور المشاريع (SVG) ونسخة السيرة الذاتية `cv.pdf` |

## ✨ المميزات

- وضع داكن افتراضي أنيق + وضع نهاري (يُحفظ الاختيار في `localStorage`).
- تبديل عربي/إنجليزي كامل مع تبديل تلقائي لـ `dir` و`lang` وبيانات SEO.
- Navbar ثابت بتأثير Glassmorphism + شريط تقدم + إبراز القسم النشط + قائمة جوال.
- Hero بصورة شخصية بإطار متحرك، إحصائيات، وأزرار تواصل/تحميل CV.
- أقسام: نبذة، مهارات (4 فئات)، معرض أعمال بفلاتر، خط زمني للخبرات، تواصل، تذييل.
- حركات دخول عند التمرير (IntersectionObserver) مع دعم `prefers-reduced-motion`.
- نموذج تواصل يتحقق من المدخلات ويفتح تطبيق البريد برسالة جاهزة (لا يحتاج خلفية).
- صور SVG محلية لبطاقات المشاريع: خفيفة، حادة على كل الشاشات، وتعمل دون إنترنت.
- بيانات منظمة JSON-LD (Person) لمحركات البحث + Open Graph.

## ✏️ التخصيص السريع

1. **النصوص والترجمات:** عدّل الكائن `I18N` في أعلى `app.js` (مفتاح `ar` و`en`).
2. **المهارات:** عدّل مصفوفة `SKILL_GROUPS` في `app.js`.
3. **المشاريع:** عدّل مصفوفة `PROJECTS` (الصورة من `assets/`، رابط `link`، التصنيف `category`).
4. **الخبرات:** عدّل مصفوفة `EXPERIENCE` في `app.js`.
5. **بيانات التواصل:** ابحث عن `mhamd77deep@gmail.com` و`966568027856` وعدّلها في:
   - `index.html` (روابط الهيرو، بطاقات التواصل، التذييل، JSON-LD)
   - `app.js` (دالة إرسال النموذج `mailto:`)
6. **السيرة الذاتية:** استبدل `assets/cv.pdf` بملفك المحدث؛ زر التحميل يشير إليه مباشرة.
7. **الصورة الشخصية:** حاليًا تستخدم صورة حساب GitHub من الرابط في `index.html`. ضع صورتك في `assets/profile.jpg` ثم استبدل قيمة `src` في عنصر `#profilePhoto`. يوجد بديل تلقائي بحروف الاسم إذا تعذّر تحميل الصورة.
8. **LinkedIn:** الرابط الحالي `https://www.linkedin.com/in/your-username/` عنصر نائب — استبدله برابطك الحقيقي في `index.html` (ثلاثة مواضع).
9. **رابطCanonical:** استبدل `https://example.com/` في `<head>` بنطاقك عند النشر.
10. **الألوان:** عدّل المتغيرات `--accent` و`--accent-2` و`--bg` في أعلى `styles.css`.

## 📝 ملاحظة عن نموذج التواصل

النموذج يعمل دون خادم: بعد التحقق من المدخلات يفتح تطبيق البريد الافتراضي برسالة جاهزة. إذا أردت استقبال الرسائل داخل الموقع، اربطه بخدمة مثل Formspree أو Web3Forms عبر استبدال جزء `window.location.href = mailto` في دالة `setupContactForm()` بطلب `fetch`.
